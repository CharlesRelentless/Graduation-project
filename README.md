# Graduation Project — 毕业论文全流程支持仓库

> 三位一体：科研辅助工具 + 遥感地物提取手册 + 论文参考数据  
> 最终目标：蒸馏为 Skill，指导学生完成遥感地物提取类毕业论文

---

## 仓库导航

| 目录 | 说明 | 面向对象 |
|------|------|---------|
| **[01-research-assistant](./01-research-assistant/)** | 科研辅助工具：EndNote、论文排版、三线表、文献检索 | 写毕业论文的学生 |
| **[02-remote-sensing-manual](./02-remote-sensing-manual/)** | 遥感地物提取操作手册：技术路线选择、数据预处理、分析流程 | 做遥感方向的学生 |
| **Data/** | 往届遥感相关毕业论文（本地私域，不公开） | 教师指导参考 |

---

## 使用流程

```
学生写遥感地物提取论文
    │
    ├─ 第一步：看 01-research-assistant
    │   学会用 EndNote 管文献、设置多级列表、做三线表
    │
    ├─ 第二步：读 02-remote-sensing-manual
    │   确定地物类型 → 选择技术路线 → 按路径执行分析
    │
    └─ 参考：Data/ 往届论文
        了解论文结构、方法选择、图表规范
```
