## 第一步：定方向（你要提取什么，在哪里提）

你的论文方向由两个要素决定：**目标地物** + **研究区**。

### 1.1 常见地物类型

| 地物类别 | 典型研究问题 | 关键特征 |
|---------|------------|---------|
| **水体** | 湖泊/河流提取、水域变化监测 | 光谱特征明显（NDWI） |
| **植被/作物** | 作物分类、长势监测、森林覆盖 | 光谱特征（NDVI）、物候特征 |
| **建设用地** | 城市扩张、不透水面提取 | 纹理特征、光谱指数（NDBI） |
| **湿地** | 湿地分类、退化监测 | 多源数据融合（光学 + 雷达） |
| **裸地/沙漠** | 荒漠化监测 | 光谱特征、时序分析 |
| **特定目标** | 光伏板、大棚、道路、滑坡体 | 结合纹理 + 形状特征 |

### 1.2 研究区选择原则

- ✅ **范围适中**：太大处理不动，太小没意义（建议单景影像覆盖为宜）
- ✅ **数据可得**：确保有对应时相的遥感影像（Landsat/Sentinel/高分）
- ✅ **验证可行**：能找到或采集验证样本（野外点、高分辨率影像目视解译）

### 3.1 路径 A0（简单监督分类）- 快速上手

#### 对应论文章节结构

```
第一章 引言
第二章 研究区概况及数据预处理
第三章 监督分类与精度评价 ⭐
├─ 3.1 样本采集
├─ 3.2 最大似然法分类
├─ 3.3 精度评价（混淆矩阵）
└─ 3.4 结果分析
第四章 结论与展望
```

#### 数据预处理要求

**特点**：需要人工构建特征，对光谱信息要求高

**必须完成的步骤：**
- 辐射定标（转换为 TOA 反射率）
- 大气校正（⚠️ **必须做**！NDVI/NDWI 依赖真实反射率）
- 去云处理（云像元会干扰分类）
- 裁剪到研究区

**关键把控点：**
- ✓ 大气校正必须做（光谱指数计算的基础）
- ✓ 光谱曲线符合常识（水体近红外<0.1，植被近红外>0.3）
- ✓ 边界对齐（叠加矢量检查）

#### 数据分析方法（第三章）

**操作步骤：**

**1. 样本采集**（30-50 个点/类）
- 在 ENVI/ArcGIS/QGIS 中绘制训练区（ROI）
- 导出训练样本文件

**2. 执行分类**（以最大似然法为例）
```
ENVI 操作流程：
1. Toolbox → Classification → Supervised Classification → Maximum Likelihood
2. 输入影像文件
3. 加载训练样本
4. 设置输出路径
5. 运行
```

**3. 精度评价**
- 用 30% 的验证样本生成混淆矩阵
- 查看总体精度和 Kappa 系数
- 如果精度<75%，检查样本质量或增加样本数量

**4. 结果分析**
- 各地物类型面积统计
- 空间分布描述
- 精度分析（哪些类别容易分错）

### 3.2 路径 A（传统机器学习）- 特征工程 + 分类器

#### 对应论文章节结构

```
第一章 引言
第二章 研究区概况及数据预处理
第三章 特征构建与分类方法 ⭐
├─ 3.1 特征变量选择
│   ├─ 光谱特征（原始波段、PCA）
│   ├─ 光谱指数（NDVI、NDWI、NDBI）
│   └─ 纹理特征（GLCM）
├─ 3.2 特征重要性评估
├─ 3.3 随机森林/SVM 分类
└─ 3.4 精度评价
第四章 结果分析与讨论 ⭐
├─ 4.1 分类结果空间分布
├─ 4.2 不同特征组合的精度对比
├─ 4.3 误差来源分析
└─ 4.4 与已有产品对比（可选）
第五章 结论与展望
```

#### 数据预处理要求

**特点**：需要人工构建特征，对光谱信息要求高

**必须完成的步骤：**
- 辐射定标
- 大气校正（⚠️ **必须做**！）
- 去云处理
- 裁剪到研究区

**可选步骤（根据需要）：**
- 主成分分析（PCA）：降维，减少特征维度
- 纹理特征构建：GLCM 提取（增强分类效果）
- 地形校正：山区需要考虑

**关键把控点：**
- ✓ 大气校正必须做（光谱指数计算的基础）
- ✓ 光谱曲线符合常识
- ✓ 边界对齐（叠加矢量检查）

#### 数据分析方法（第三、四章）

**A1. 样本采集**（耗时最长，占 40% 工作量）

**操作清单：**
- 每类地物至少采集 50-100 个样本点/多边形
- 样本均匀分布，覆盖整个研究区
- 按 7:3 分为训练样本和验证样本
- 检查是否有"同物异谱"或"异物同谱"现象

**A2. 特征构建**

**光谱特征：**
- 原始波段：所有可用波段
- 主成分分析（PCA）：降维，提取主要信息

**光谱指数（根据地物选择）：**

| 指数名称 | 公式 | 适用地物 |
|---------|------|---------|
| NDVI | (NIR-Red)/(NIR+Red) | 植被/作物 |
| NDWI | (Green-NIR)/(Green+NIR) | 水体 |
| NDBI | (SWIR-NIR)/(SWIR+NIR) | 建设用地 |
| SAVI | 土壤调节植被指数 | 稀疏植被 |
| EVI | 增强型植被指数 | 高覆盖植被 |
| MNDWI | 改进归一化差异水体指数 | 城镇区域水体 |

**纹理特征（GLCM 灰度共生矩阵）：**
- 均值、方差、熵、对比度、相异性

**A3. 特征选择**
- 计算特征重要性（随机森林自带）
- 剔除重要性低的特征，防止维度灾难

**A4. 分类器选择**

| 分类器 | 优点 | 适用场景 |
|-------|------|---------|
| 随机森林 | 鲁棒、可解释性强、不易过拟合 | 首选，适合多数场景 |
| SVM | 小样本效果好 | 样本量<100/类 |
| 最大似然 | 简单快速 | 样本满足正态分布时 |

**A5. 分类后处理**
- 中值滤波/多数滤波去除小斑块
- 面积阈值过滤（去除小于指定面积的图斑）

**A6. 结果分析**（第四章内容）
- 分类结果空间分布图
- 不同特征组合的精度对比试验
- 误差来源分析（混淆矩阵）
- 与已有产品对比（如 GlobeLand30）

#### 数据预处理要求

**特点**：端到端学习，需要大量标注样本

**必须完成的步骤：**
- 辐射定标 + 大气校正（保证影像质量稳定）
- 几何精校正（⚠️ **必须精确**！标签与影像像素级对齐）
- 去云处理（云区会影响模型训练）
- 制作标签（⚠️ **最耗时**！像素级标注）
- 样本切片（切成 256×256 或 512×512 小块）
- 数据增强（旋转、翻转、亮度调整）

**关键把控点：**
- ✓ 标签与影像精确对齐（像素级）
- ✓ 样本分布均匀（覆盖不同光照、角度）
- ✓ 切片尺寸合理（256 或 512，根据显存大小）
- ✓ 训练集/验证集独立（不要混用）

**特别注意：**
- ⚠️ 标签质量决定模型上限（垃圾标注=垃圾模型）
- ⚠️ 样本量要足够（至少 500 张有效切片）
- ⚠️ 类别不平衡问题（某些地物样本太少）

#### 数据分析方法（第三、四章）

**B1. 数据准备**
- 样本制作：制作与影像尺寸对应的标签图（像素级标注）
- 样本切片：将大影像切成 256×256 或 512×512 的小图块
- 数据增强：旋转、翻转、亮度调整等（提升泛化能力）

**B2. 模型选择**

| 模型 | 特点 | 适用场景 |
|------|------|---------|
| U-Net | 经典、稳定、对中小数据集友好 | 首选，适合多数任务 |
| DeepLabV3+ | 多尺度特征、边界精细 | 高分辨率影像、需要精细边界 |
| SegFormer | 轻量、速度快 | 计算资源有限时 |

**B3. 训练与调参**
- 损失函数：交叉熵（多分类）、Dice loss（类别不平衡时）
- 优化器：Adam（默认参数即可）
- 学习率：0.0001 起步，可加学习率衰减
- 训练轮数：50-100 轮，早停防止过拟合

**B4. 预测与后处理**
- 滑动窗口预测（大影像分块预测再拼接）
- CRF 后处理（可选，优化边界）

**B5. 结果分析**（第四章内容）
- 分割结果可视化（分类图）
- 精度评价（混淆矩阵、IoU、F1-score）
- 与其他方法对比（如随机森林）
- 误差分析（漏分、误分案例）
- 模型泛化能力讨论（在不同区域的迁移能力）

#### 数据预处理要求

**特点**：多时相数据，需要严格配准和辐射归一化

**必须完成的步骤：**
- 辐射定标（统一 DN 值标准）
- 大气校正（⚠️ **必须做**！消除大气影响）
- 精确配准（⚠️ **最关键**！多期影像像素级对齐）
- 辐射归一化（消除季节、太阳高度角差异）
- 去云处理（确保各期云量一致）
- 裁剪到研究区（统一范围）

**关键把控点：**
- ✓ 多期影像精确配准（误差<1 像素）
- ✓ 辐射归一化后直方图一致
- ✓ 各期云量接近（避免云引起的伪变化）
- ✓ 同一传感器、同一轨道（减少几何畸变）

**特别注意：**
- ⚠️ 配准不准会导致大量"伪变化"
- ⚠️ 太阳高度角差异会引起辐射畸变
- ⚠️ 物候差异（植被季节变化）会被误判为变化

#### 数据分析方法（第三、四章）⭐⭐

**C1. 变化检测方法**

| 方法 | 做法 | 适用场景 |
|------|------|---------|
| **差值法** | 影像直接相减，阈值分割 | 快速发现变化区域 |
| **指数差值** | NDVI/NDWI差值 | 植被/水体变化 |
| **分类后比较** | 分别分类，对比分类结果 | 知道变化前后地物类型 ⭐ |
| **深度学习** | 孪生网络（Siamese Network） | 需要精细变化检测结果 |

**C2. 时空变化分析（第三章核心）**

**数量变化分析：**
```python
# 动态度计算（必算指标）
K = (Ub - Ua) / Ua × 1/T × 100%
# Ub: 末期面积，Ua: 初期面积，T: 时间间隔（年）
```

**空间变化分析：**
- **变化分布图**：ArcGIS/QGIS 制图（哪里变了）
- **变化重心转移**：计算每个时期的重心坐标（向哪个方向移动）
- **变化热点识别**：Getis-Ord Gi* 统计量（聚集区域）

**转移矩阵分析：** ⭐必做
```
          末期
        耕地  林地  草地  建设用地
初期 耕地  -    →    →    →
     林地  ←    -    →    →
     草地  ←    ←    -    →
     建用地 ←    ←    ←    -

箭头表示转换方向，对角线表示未变化
```

**C3. 驱动力分析（第四章核心）** ⭐⭐

**驱动因子选择：**
- 自然因子：年降水量、年均温、DEM、坡度、坡向
- 人文因子：GDP、人口密度、距道路距离、距居民点距离、政策因素

**地理探测器（Geodetector）方法：** ⭐强烈推荐

```python
# 因子探测：识别驱动力的贡献率
q = 1 - (Σ(Ni * σi²)) / (N * σ²)
# q 值范围 [0,1]，q 值越大表示该因子的解释力越强
# q=0.3 表示该因子解释了 30% 的空间分异

# 交互作用探测：识别双因子的协同作用
判断规则：
- 非线性减弱：q(x1∩x2) < q(x1) + q(x2)
- 非线性增强：q(x1∩x2) > q(x1) + q(x2) ⭐常见
- 独立：q(x1∩x2) = q(x1) + q(x2)
```

**逻辑回归（Logistic Regression）：**
```python
# 分析各驱动因子对变化的影响程度
logit(P) = β0 + β1X1 + β2X2 + ... + βnXn
# P: 发生变化的概率，β: 回归系数
# |β| 越大表示影响越强，正负号表示正/负相关
```

**C4. 变化分析成果（必须准备的图表）** ⭐

**必选图件：**
- 土地利用现状图（初期、末期）
- 变化分布图（哪里变了）
- 转移矩阵图（桑基图/Sankey Diagram）⭐直观展示转换关系
- 驱动力 q 值排序图（各因子贡献率）
- 交互作用探测结果图

**必选统计表：**
- 各地类面积变化表
- 动态度计算结果表
- 转移矩阵表
- 地理探测器因子探测结果表（q 值表）

### 3.5 雷达数据预处理（适用于水体提取、作物监测）

> **适用场景**：水体提取（对云不敏感）、作物监测、地表形变、夜间观测

**标准流程：**
1. 轨道校正（Apply Orbit File）
2. 热噪声去除（Thermal Noise Removal）
3. 辐射定标（Calibrate to Sigma0）
4. 斑点滤波（Refined Lee，5×5 窗口）
5. 地形校正（Terrain Correction，使用 SRTM DEM）
6. 地理编码（投影到 WGS84 UTM）

**关键把控点：**
- ✓ 地形校正后，背坡和阳坡的亮度均匀
- ✓ 影像与光学影像/研究区边界对齐
- ✓ 水体区域的后向散射值显著低于陆地（VV < -15 dB）

## 第四步：执行质量检查

### 4.1 样本质量检查（路径 A/B 都适用）

**检查清单：**
- ✓ 样本数量：路径 A 每类>50 个；路径B 像素级标注>500 个图块
- ✓ 样本分布：是否均匀覆盖研究区
- ✓ 样本质量：是否有"同物异谱"或"异物同谱"

### 4.2 特征/模型合理性检查

**路径 A 检查点：**
- ✓ 特征是否太多？有没有做特征选择？
- ✓ 分类器选择是否合理？（小样本用 SVM，样本够用随机森林）

**路径 B 检查点：**
- ✓ 模型是否太大？（数据量小不要硬上 DeepLabV3+，U-Net 更稳妥）
- ✓ 训练过程是否正常？（loss 下降，验证精度上升）

### 4.3 精度达标检查

**硬性指标：**

| 指标 | 一般要求 | 精细任务要求 |
|------|---------|-------------|
| **总体精度** | >85% | >90% |
| **Kappa 系数** | >0.7 | >0.8 |
| **分地类精度** | 主要地物>80% | 所有地物>85% |

**必须准备：**
- ✓ 混淆矩阵表
- ✓ 各类别精度（生产者精度、用户精度）
- ✓ 精度分析报告（哪一类低？为什么低？）

### 4.4 结果可信度检查

**目视检查：**
- ✓ 分类图看起来合理吗？（没有严重"椒盐噪声"）
- ✓ 边界基本对齐影像吗？
- ✓ 面积统计符合常识吗？（水体面积不会突然翻倍）

**变化结果验证：**
- ✓ 有实地验证或高分辨率影像验证吗？
- ✓ 变化区域是否在逻辑上合理？

## 附录：常见问题 FAQ

### Q1: 我的研究区云太多怎么办？

**解决方案：**
1. 选择云量少的影像（重新选时相）
2. 去云处理（Fmask、Sen2Cor 等）
3. 改用雷达数据（Sentinel-1，不受云影响）

### Q2: 样本采集太慢了，有什么捷径？

**解决方案：**
1. 使用已有样本库（如 GlobeLand30、FROM-GLC）
2. 半自动采集（先目视解译一部分，再用主动学习迭代）
3. 众包采集（发动同学一起标注）

### Q3: 随机森林和 SVM 哪个更好？

**答案：**
- 大多数情况下**随机森林**更鲁棒
- 样本很少（<50/类）时**SVM**可能更好
- 实际测试：两个都跑，选精度高的

### Q4: 深度学习模型不收敛怎么办？

**排查清单：**
1. 检查数据预处理（归一化、标签格式）
2. 降低学习率（从 0.0001 开始）
3. 检查样本质量（标注是否正确）
4. 简化模型（先用 U-Net，不要上复杂模型）

### Q5: 精度一直上不去怎么办？

**解决思路：**
1. **检查样本**：增加样本数量、改善样本质量
2. **检查特征**：增加区分度高的特征（指数、纹理）
3. **检查类别**：合并难以区分的类别
4. **换方法**：机器学习→深度学习，或反之
